# RenderDiagnostics

C# editor-only plugin scaffold for MiniForge.

- Protocol: `miniforge-plugin-command-v1`
- Intended use: editor panels, automation commands, OpenGL compatibility tooling and Metal diagnostics.
- Export policy: `exclude`; this plugin is not copied into runtime builds.

Run locally with:

```bash
dotnet run --project src/RenderDiagnostics.csproj
```
